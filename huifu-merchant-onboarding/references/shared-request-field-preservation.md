# 进件请求字段保留规则

## 核心原则

调用方已经接收并校验的业务字段必须原样传给 SDK；不要为了示例方便重写日期、流水、商户号、申请单号或材料标识。

## 高风险字段

| 字段 | 规则 |
| --- | --- |
| `req_date` | 使用调用方业务日期；格式非法时报错 |
| `req_seq_id` | 使用调用方幂等流水；不要用当前时间覆盖 |
| `huifu_id` | 只使用当前真实商户号；接口没有该字段时不伪造 |
| `apply_no` | 状态查询使用真实申请单号 |
| `file_id/file_url` | 使用已授权材料标识；不得替换成官网示例 |
| `upper_huifu_id` | 保留真实归属关系；不得根据 `sys_id` 猜测 |

## 生成条件

- 字段存在、类型合法且调用方已确认来源时才赋值。
- 条件字段必须先判断触发条件。
- 缺失或非法时返回明确错误，不静默生成替代值。
- 官网示例值不作为默认值。
