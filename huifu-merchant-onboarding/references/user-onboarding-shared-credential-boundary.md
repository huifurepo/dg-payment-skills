# 用户开户凭据与敏感数据边界

## 密钥

- RSA 私钥、密钥口令和完整商户配置仅保存在服务端密钥管理系统或受控挂载中。
- 禁止提交仓库、写入前端、拼入命令行、日志、异常、测试快照或回答示例。
- SDK 调试日志必须在任何配置和请求加载前关闭；同时保持运行时正常证书链和主机名校验，不得主动关闭或安装 trust-all 实现。

## 业务敏感字段

以下至少按高敏处理：`login_password`、法人/个人/持卡人证件号、银行卡号、手机号、邮箱、详细地址、文件 ID、`token_no`、签约协议号、签名及完整原始响应。

- `login_password` 是条件返回的初始密码，只能通过一次性受控通道交付；读取后不再回显。
- 日志采用字段白名单，只记录脱敏流水、接口、结果层和审计 ID；禁止先记录完整对象再做后处理脱敏。
- 查询响应只提取当前业务所需字段；证件、银行卡和附件列表不得完整传给前端。
- 测试使用结构正确的假值，不能复制官方示例中的真实感证件号、卡号、手机号或密码。

## 用户号边界

用户 `huifu_id` 本身是业务标识，不应据此访问其他主体数据。每次查询或入驻都校验其与 `sys_id`/上级主体的授权关系；SDK 类存在不等于获得访问权限。
