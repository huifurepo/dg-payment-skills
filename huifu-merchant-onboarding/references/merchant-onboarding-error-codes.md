# 商户进件错误处理

官方公共来源：

- [返回码](https://paas.huifu.com/partners/api/doc/csfl/api_csfl_ywm.md)：HTTP/网关返回码以及“商户进件返回码”等业务分类的全集。
- [基础参数汇总](https://paas.huifu.com/partners/api/doc/csfl/api_csfl.md)：地区、银行、支行、MCC、文件类型等公共编码入口。
- [名词解释](https://paas.huifu.com/partners/api/doc/csfl/api_csfl_mcjs.md)：商户、结算、手续费等术语口径。

当前接口页的专属返回码与公共返回码必须合并排查。公共页提供取值和分类，不覆盖具体接口页对 `resp_code` / `sub_resp_code` 的字段长度、外层结构和必填性；不同接口快照出现 5 位或 6 位网关字段时，保留各自字段合同，不擅自统一类型。

## 通用层次

1. HTTP/网关错误：先检查网络、环境、请求头和报文格式。
2. 网关业务响应：`resp_code` 只表示本次同步处理，不代表审核或业务开通终态。
3. 接口权限：如 `20003`，核对 `sys_id` 和接口授权。
4. 数据权限：核对 `product_id`、上下级和目标 `huifu_id` 的归属。
5. 材料/字段错误：回到完整字段目录和字段合同，检查条件字段、长度、枚举和外部资料。
6. 审核或逐业务失败：读取申请状态、详情或逐业务结果，不重复创建商户。

## 网关与业务码分层

| 层级 | 常见字段/取值 | 含义与处理 |
| --- | --- | --- |
| HTTP/网关访问层 | HTTP `200`、`404`、`412`、`500`、`502` 等 | 判断请求是否正常到达网关；不能代表商户审核或业务开通结果 |
| 网关业务层 | `resp_code`，如 `10000` 成功调用、`20001` 权限不足、`40001` 无效参数、`40002` 验签失败 | 判断网关受理、权限和验签；字段长度以当前接口表为准 |
| 商户进件业务层 | 同步 `data.resp_code` 或异步 `data.sub_resp_code` 等 8 位业务码 | 结合对应 `resp_desc`、接口、申请状态和逐业务结果排查 |

`00000000` 只表示本次接口业务处理完成，不等于审核通过、业务已开通或商户可交易。异步 `sub_resp_code` 也不能脱离通知类型、审核状态和业务开通结果单独驱动终态。

## 固定边界

- 不根据错误文案猜费率、准入或审核结论。
- 不通过更换 `req_seq_id` 并发重试同一业务动作。
- 未知错误整理脱敏请求、响应、申请号、时间和 SDK 版本后升级人工。
- 本页未摘录的返回码先查官方公共全集及当前接口页，不得把“未在本页列出”直接解释为未知系统错误。
