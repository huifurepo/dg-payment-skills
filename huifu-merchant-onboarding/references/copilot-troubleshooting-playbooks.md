# 商户进件问题排查 Playbook

## 输出结构

| 项 | 内容 |
| --- | --- |
| 问题判断 | 主体、接口和阶段 |
| 可能原因 | 按概率列 2–4 项 |
| 先检查 | 权限、归属、材料、请求、状态 |
| 修复动作 | 可执行修改或补充 |
| 验证方式 | 详情、申请状态或逐业务结果 |
| 升级人工 | 停止自动判断的条件和脱敏材料 |

## 高频问题

| 问题 | 先检查 | 结论 |
| --- | --- | --- |
| 基础进件返回成功但不能交易 | 是否已有 `huifu_id`、业务开通、绑卡、结算、取现和渠道结果 | `huifu_id` 只表示本次响应返回了商户标识；不能单独推导账户创建、审核通过或可交易 |
| 接口权限认证失败 / `20003` | `sys_id`、环境、接口路径、权限 | 整理材料申请接口权限，不改字段碰运气 |
| 数据权限认证失败 | `product_id`、`sys_id`、`upper_huifu_id`、`huifu_id` 归属 | 修正层级关系，不猜商户归属 |
| 业务开通部分失败 | `reg_result_list[]`、逐业务异步和申请状态 | 按业务逐项处理，不把同步成功当整体完成 |
| 实名状态延迟 | 主体、证件、绑卡/短信、详情与申请状态 | 继续查询或补资料，不重复创建商户 |
| 图片失败 | 格式、大小、`file_url/file` 互斥、SDK 路径 | 不猜响应文件标识；本地文件流未确认时停止 |
| 请求头缺失 | `skill_source`、当前请求是否真实含 `huifu_id`、SDK 版本 | 不为补头污染业务 data |
| 回调实现不确定 | 是否有官方原始样本、签名和 ACK 协议 | 未确认时只整理确认清单 |

## 升级人工

费率、合规、资质审核、通道准入、生产故障定责、官方资料冲突或协议缺失时，只整理：环境、接口、SDK 版本、脱敏主体/申请标识、脱敏请求响应、时间线、日志、影响范围和已做动作。不得包含真实密钥、身份证、银行卡、手机号或图片。
