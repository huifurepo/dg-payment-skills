# 支付 Skill 版本策略

## 当前版本

| 项目 | 口径 |
| --- | --- |
| Skill | `huifu-pay-integration 1.5.0` |
| 能力 | 聚合支付、托管支付、余额支付及其辅助接口、checkout-js、支付通知、本地沙箱和上线检查 |

## 更新方式

- Git：拉取维护方仓库后整体替换 `huifu-pay-integration`。
- 独立包：验证包 SHA 后整体替换，不混合新旧 reference。
- 同时需要进件：单独安装或升级 `huifu-merchant-onboarding`，两个 Skill 不要求同版本号。

版本回答必须说明：Skill 不能主动联网检查或推送升级；只有用户触发版本问题时提示。未显式配置 `skill_source` 时，按当前请求实际参与生成的 Skill 集合取值：仅支付使用既有来源值 `hfps/1.5.0`；支付与进件都实际参与当前请求时使用 `hfps/1.5.0;hfms/1.1.0`。仅安装或加载但未参与本次生成的不计入；显式合同值优先并原样透传。
